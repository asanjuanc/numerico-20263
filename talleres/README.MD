# numerico-20263 — Taller 1: Autopsia numérica

Repositorio para entregar el código de Julia del Taller 1 (Evidencia C: máquina de punto flotante, condicionamiento y estabilidad).

## Cómo subir tu archivo (sin instalar nada)

1. Entra a este repositorio en tu navegador.
2. Da clic en **"Add file" → "Create new file"** (o "Upload files" si ya tienes el `.jl` en tu computador).
3. En el nombre del archivo, escribe tu nombre completo separado por guiones, todo en minúsculas, sin tildes ni espacios. Ejemplo:

   ```
   fulano-sutano-perensejo.jl
   ```

   Si trabajaste en grupo, sube **un solo archivo** con el nombre de uno de los integrantes (no hace falta subir uno por persona).

4. Pega o escribe tu código Julia en el recuadro.
5. Baja hasta el final de la página. Como no eres colaborador de este repositorio, GitHub te va a mostrar un mensaje como *"Proponer cambios en tu propia copia"* — es normal, no te saltaste ningún paso. Dale clic al botón verde (algo como **"Propose changes"** o **"Commit changes"**).
6. En la siguiente pantalla, dale clic a **"Create pull request"**.
7. Listo. Ya quedó entregado — no necesitas hacer nada más ni avisarme por otro medio.

## ¿Qué debe contener tu archivo?

- El código Julia de la Evidencia C (algoritmo ingenuo, algoritmo estable, tabla comparativa).
- Al final, como comentario (`#`), tu párrafo de veredicto forense.
